# Avid — 分阶段开发路线

> 使用方式：每个阶段只做当前阶段，完成后确认，再进入下一阶段。
> 铁律：**验收只认参考场景（见 requirements.md §2.1），不认"模块写完了"。**

每个阶段包含四要素：目标 / 产出 / 验收 / 下一步启动前提。

---

## 阶段 0 — 需求冻结 + 工程基线

- **目标**：说清"做哪种 agent、什么算成功"，并让仓库能跑、能提交。
- **产出**
  - `docs/requirements.md` 冻结为 v1（含决策记录与参考场景 R）
  - `docs/roadmap.md`（本文件）
  - git 仓库 + `.gitignore`（排除 `.env` / `.venv` / `__pycache__`）+ `uv` 依赖管理
  - 目录骨架：`src/`、`tests/`、`docs/`
  - 最小程序：读环境变量 → 发一次真实模型调用 → 打印回复与 token 用量
  - `README.md`：安装、配置、运行三步
- **验收**
  - 一条命令跑通并打印**真实**模型回复与 token 用量
  - 缺少 API Key 时给出清晰报错，而不是堆栈
  - `git log` 存在首个提交；README 能让"明天的你"三步复现
- **下一步启动前提**：需求文档签字确认 **且** 最小模型调用跑通。

---

## 阶段 1 — 最小 Agent 环（tracer bullet）

- **目标**：让"模型 → 工具 → 模型"的完整往返跑通一次，只做 1 个工具。
- **产出**：工具注册机制与 schema 定义；`read_file` 工具（参考场景 R 的第一个工具）；
  一次完整 tool-call 往返；结构化 trace 日志（请求 / 工具调用 / 结果回填 / 最终答复）。
- **验收**：对参考场景 R 中一个必然触发 `read_file` 的问题，agent 自主调用工具并给出正确答案；
  trace 能逐条看清上述四次交换，无人工干预。
- **下一步启动前提**：闭环稳定、日志可读，重跑结果一致。

---

## 阶段 2 — 多步循环与错误处理

- **目标**：从"一次调用"到"连续行动直到任务完成"。
- **产出**：循环控制与最大步数；工具错误回传给模型自纠；超时与重试；
  终止原因分类（完成 / 超步数 / 工具失败 / 模型放弃）。
- **验收**：参考场景 R 中需要 ≥3 次工具调用的问题能完成；
  工具报错时 agent 要么自我修正、要么明确放弃并说明原因；同输入基本同路径。
- **下一步启动前提**：循环行为可预测，终止原因可读。

---

## 阶段 3 — 状态持久化与上下文管理

- **目标**：会话可续、上下文不溢出、成本可控。
- **产出**：会话落盘与恢复；历史裁剪 / 摘要策略；token 预算与用量统计。
- **验收**：重启进程后能继续上次会话；长会话不超模型上限；每轮 token 与成本可见。
- **下一步启动前提**：上下文策略有实测数据支撑，而非拍脑袋。

---

## 阶段 4 — 评测与可观测闭环（分水岭）

- **目标**：把"感觉变好了"变成"通过率变了"。
- **产出**：参考场景 R 的 10–20 条评测集；自动运行器；
  指标（成功率 / 平均步数 / 成本 / 时延）；trace 回放；与基线的对比报告。
- **验收**：一条命令输出评测报告；能对比两次改动的差异；基线分数已冻结。
- **下一步启动前提**：回归能力可用——改坏东西能被立刻发现。

---

## 阶段 5 — 安全边界与权限模型

- **目标**：让它能碰真实文件和命令而不失控。
- **产出**：权限分级；危险操作确认；工作区 / 沙箱边界；审计日志。
- **验收**：越界操作被拦截并留痕；只读任务在物理上无法写文件；
  阶段 4 的评测集在引入权限后仍全绿。
- **下一步启动前提**：安全模型经确认。

---

## 阶段 6 — 长期记忆与个性化

- **目标**：跨会话积累，越用越顺手。
- **产出**：记忆写入 / 检索 / 优先级 / 遗忘；用户偏好注入。
- **验收**：新会话能复用此前明确告知的偏好；记忆可查看、可删除；
  不影响阶段 4 基线（不引入回归）。
- **下一步启动前提**：记忆的收益可被评测数字证明。

---

## 阶段 7 — 扩展与产品化（按需，顺序可调）

- 子任务分解 / 子 agent 分派
- TypeScript Web GUI
- 工具生态扩展、协议互操作（MCP 等）
- 打包与分发

> 阶段 5 与 6 先后可调；阶段 4 不可跳过。
